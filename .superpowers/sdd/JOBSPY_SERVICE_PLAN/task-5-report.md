## 1. Executive Summary

Task 5 replaces append-only vacancy creation with URL-based upserting and in-batch URL deduplication. Existing database vacancies matching a scraped URL have their source-owned fields refreshed while preserving all user and workflow state. Unwanted duplicate writes within single scrape batches are prevented, and missing/blank URLs are logged and skipped.

## 2. Key Changes & File Modifications

### 2.1 Database Model & Alembic Migration
- **`src/ljpa_reworked/models/database_models.py`**:
  - Updated `Vacancy.url` to `Mapped[str | None] = mapped_column(String(500), nullable=True, unique=True)`.

  - Implemented preflight read-only duplicate check in `upgrade()` to raise an explicit `ValueError` if duplicate non-null URLs exist in database prior to constraint application.

### 2.2 Vacancy Operations
- **`src/ljpa_reworked/operations/vacancy_ops.py`**:
  - Implemented `upsert_vacancy_by_url(db: Session, vacancy_data: dict) -> tuple[Vacancy | None, bool]`:
    - Skips records with missing or blank `url` (logs warning, returns `(None, False)`).
    - On new URL: creates `Vacancy` with initial status `VacancyStatus.created` and returns `(vacancy, True)`. Handles `IntegrityError` race conditions with rollback and re-query.
    - On existing URL: updates ONLY source-owned fields (`title`, `text`, `credentials`, `source`, `visa_status`) and returns `(existing_vacancy, False)`.
    - Preserves `id`, `created_at`, `status`, `deleted`, `basic_evaluation`, `resumes`, `emails`, `telegram_status`, and all workflow relationships.

### 2.3 JobSpy Service Integration
- **`src/ljpa_reworked/services/jobspy.py`**:
  - Updated `fetch_and_store_jobs` and added internal `_store_jobs_df` helper.
  - Implemented batch deduplication using a `seen_urls` set within each scrape run.
  - Skips empty/blank `job_url` rows after whitespace trimming.
  - Calls `upsert_vacancy_by_url` to persist/refresh job records.

### 2.4 Unit Tests
- **`tests/test_task5_url_upsert.py`**:
  - `test_create_vacancy_on_first_url_scrape`: Verifies initial vacancy creation with status `created`.
  - `test_refresh_source_owned_fields_on_second_scrape`: Verifies update of source fields (`title`, `text`, `credentials`, `source`, `visa_status`) on matching URL.
  - `test_preserve_workflow_data_and_status_on_refresh`: Verifies that status (e.g. `applied`), `created_at`, and `basic_evaluation` relations are preserved upon refresh.
  - `test_skip_missing_or_empty_url`: Verifies that missing or whitespace-only URLs are skipped.
  - `test_repeated_same_url_in_single_scrape_batch`: Verifies that duplicate URLs in a single scrape batch result in exactly one DB write.
